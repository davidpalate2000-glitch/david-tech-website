# Data Security IT — Revamped Website

This version adds:
- photography-led service cards and gallery
- client review section with honest placeholders
- responsive mobile navigation
- stronger calls to action
- About section
- contact CTA using info@datasecurityit.kiwi

## Replace the stock/reference photos
The current images are Creative Commons images hosted by Wikimedia Commons. They are included as remote images so the GitHub repository stays small. For your final business site, replace them with your own installation/project photos.

## Reviews
Do not publish invented testimonials. Replace the placeholder review cards with real customer comments and permission to publish them.

## Deploy
Copy `index.html`, `style.css`, and `script.js` over the files in your existing repository, then:

git add .
git commit -m "Revamp Data Security IT website"
git push
